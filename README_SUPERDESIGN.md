## 🛠️ **Stack Tecnológico**

- **Frontend**: React 18 + TypeScript + Vite
- **UI**: shadcn/ui + Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth + RLS)
- **Gráficos**: Recharts
- **Roteamento**: React Router v6
- **Estado**: React Context + Custom Hooks
